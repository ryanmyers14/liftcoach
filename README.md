# LiftCoach

A phone-first workout tracker and progressive overload coach. Log your sets and the coach tells you what to lift next.

Open the app: https://ryanmyers14.github.io/liftcoach/

Your data is saved only in your own browser, so everyone who opens the link gets their own separate data.

Built for a CS 124 project at the University of Illinois. Plain HTML, CSS, and JavaScript with no build step.
